# Das Schafgehege

Lernspiel für Mathematik Klasse 9 (Extremwertaufgaben mit quadratischen Funktionen).
Schülerinnen und Schüler bauen mit einer festen Anzahl Zaunteile rechteckige Gehege und erfüllen die Aufträge der Bauern.

- Spiel: `index.html` (läuft komplett im Browser, keine Anmeldung, keine Datenübertragung)
- Lehreransicht: Link „Lehrkraft: Beamer-Ansicht“ auf der Startseite bzw. `#beamer` an die Adresse anhängen
